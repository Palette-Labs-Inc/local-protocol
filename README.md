# Local Protocol

This repository defines a modular commerce protocol with capability-focused
specification docs and machine-readable schemas. The initial capability is
Delivery Quotes.

## Layout

- `docs/` — human-readable documentation by domain
  - `docs/delivery/` — delivery capability documentation
- `schemas/` — JSON Schemas by domain
  - `schemas/delivery/` — delivery capability schemas
- `bindings/` — protocol bindings for other ecosystems
  - `bindings/ucp/` — UCP-specific discovery and integration notes
