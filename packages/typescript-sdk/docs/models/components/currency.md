# Currency

Currency descriptor (fiat or EVM token).


## Supported Types

### `components.FiatCurrency`

```typescript
const value: components.FiatCurrency = {
  symbol: "<value>",
};
```

### `components.EvmCurrency`

```typescript
const value: components.EvmCurrency = {
  chainId: 944542,
  address: "27056 Mills Wall",
  decimals: 924120,
};
```
