# IntervalUnion

A single time interval for a day of the week or a specific date.


## Supported Types

### `components.Interval1`

```typescript
const value: components.Interval1 = {
  day: "<value>",
  fromHour: 658320,
  fromMinute: 172238,
  toHour: 18742,
  toMinute: 568543,
};
```

### `components.Interval2`

```typescript
const value: components.Interval2 = {
  date: new Date("2024-04-05"),
  fromHour: 643559,
  fromMinute: 876174,
  toHour: 868973,
  toMinute: 675827,
};
```
