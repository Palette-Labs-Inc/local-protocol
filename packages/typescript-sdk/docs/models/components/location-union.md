# LocationUnion

A location specified by coordinates and/or postal address. At least one must be provided.


## Supported Types

### `components.Location1`

```typescript
const value: components.Location1 = {
  coordinates: {
    latitude: 1526.08,
    longitude: 5253.35,
  },
};
```

### `components.Location2`

```typescript
const value: components.Location2 = {
  postalAddress: {},
};
```
