# Media

Shared media object used for catalog items, products, and other assets.

## Fields

- `type` (string, required): Media type (`image`, `video`, `model_3d`).
- `url` (string, required): URL to the media resource.
- `alt_text` (string, optional): Accessibility text describing the media.
- `width` (integer, optional): Width in pixels.
- `height` (integer, optional): Height in pixels.
