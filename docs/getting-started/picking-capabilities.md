# Picking Capabilities

Start by choosing the smallest set of capabilities your product needs. Each capability is a set of schemas and behaviors that you can adopt independently.

## How to choose

1. List the user actions you need to support (e.g., request a delivery, provide a delivery bid).
2. Map each action to a capability (Delivery covers bids/asks; Payment covers escrow settlement).
3. Implement the minimum objects you need to exchange, then add more as your flow grows.
